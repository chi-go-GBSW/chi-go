# chi-go

GBSW 팀 프로젝트 모노레포입니다.

## 구조

```
chi-go/
├── apps/
│   ├── mobile/    React Native 모바일 앱
│   ├── backend/   백엔드 서버
│   └── ai/        AI 파트
```

각 파트는 담당자가 자신의 스택에 맞게 직접 초기 설정 후 커밋합니다.
자세한 설치/실행 방법은 각 폴더의 README.md를 참고하세요.
